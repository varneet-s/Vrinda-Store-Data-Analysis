# Raw Data Overview

## Dataset Description
The dataset contains Vrinda Store sales data for the year 2022.
[Vrinda Store Data Analysis.xlsx](https://github.com/user-attachments/files/27119069/Vrinda.Store.Data.Analysis.xlsx)


## Key Columns
- Order ID
- Date
- Gender
- Age
- State
- Channel (Amazon, Flipkart, Myntra)
- Category
- Sales Amount
- Order Status

## Data Issues Identified

1. **Inconsistent Gender Labels**  
   - Values included: `M`, `Men`, `W`, `Women`  
   - These represent the same categories but were stored inconsistently  

2. **Quantity Column Format Issue**  
   - Some values were written as words (`one`, `two`) instead of numbers (`1`, `2`)  

## Initial Observations
- Multiple sales channels present
- Demographic data available (age, gender)
- Geographic segmentation possible
